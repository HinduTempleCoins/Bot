Outflow approval

The browser wallet and the downloadable SoapBox Miner app are the same wallet (one seed). Receiving and mining never need this toggle. When sending arrives, money can only leave while this is flipped to Approve — it re-locks after a send. Default is Locked.

Not wired yet: sending coins out of the browser wallet does not exist in this build — this toggle shows the approval pattern the wallet will use. The downloadable app inherits the same one-wallet + approve-to-send rule when sending ships (with PRANA / the Akasha wallet).
