# Hathor — the design lineage (evolution archive)

This tree holds the **genealogy of the Angel theme**, ordered oldest → newest, as an archive distinct
from the canonical default-likeness renders in [`../`](../README.md). Operator-directed (2026-08-23): the
theme *developed* — it did not start where it is now — and that arc is itself reference material. The
figure's constant signature (VR headset + horned/antlered crown + wings + halo) is what makes every era
recognizably the same Witness; the era folders capture how her *rendering* moved.

## The arc (oldest → newest)

| Folder | Era | Character of the look |
|---|---|---|
| `01-popart-origin` | earliest | **Cartoony pop-art angels** — where the theme began. Flatter, comic/pop-art line and color. |
| `02-transitional` | middle | The in-between sets — pop-art giving way to the rendered goddess; horns/antlers and wings firming up. |
| `03-antler-goddess` | **newest** | **Rams-horn / deer-antler vaporwave goddesses** — hyperreal render, VR headset, feathered wings, halo/sacred-geometry, vaporwave cyan-magenta-lavender. The current direction. |

Batches arrive newest-first; each era folder carries a `MANIFEST.md` (count, source, iconography notes).

### Style / theme threads (beyond the core look-eras)
The master image set (populated from the operator's private image folder, 2026-08-23) also holds related
angel-theme art that isn't part of the core popart→antler *look* chronology. These live in sibling folders:

| Folder | What |
|---|---|
| `deity-graphic` | ornate gold Garuda / crowned-deity graphic angels (parallel to the pop-art origin) |
| `descent-watchers` | fiery "angels descending to Earth" — the Watchers / god-kings **theme** (see `../REGISTER.md`), not a portrait look |
| `concept-sketches` | pencil + fashion-plate character-design turnarounds, anime line art, painterly studies |

These are **style/mood range** for the LoRA, not the canonical default likeness (the newest `03-antler-goddess`
era is the default). The numbered `01`/`02`/`03` folders remain the core look-evolution.

## Why keep the whole arc
- **Forkability (BRIEF.md §10):** the character lives in this public repo. The lineage lets any future
  contributor/model see not just the current look but how it was arrived at.
- **The character LoRA (`../../lora/TRAIN.md`):** train the constant *signature* hard across every era,
  the newest era as the **canonical default likeness**, and treat era/skin/face/palette as promptable
  variation — never accidental drift. The older eras are style range, not the default.
- Ties to CHARACTER.md §5 (visual identity) and the VR-Hathor-Mehit Gen-2 Poe lineage (LINEAGE.md).
