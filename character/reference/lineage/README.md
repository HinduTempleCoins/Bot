# Hathor — the design lineage (aesthetic archive)

This tree is the **aesthetic archive** of the Angel theme — the collection behind the canonical
default-likeness renders in [`../`](../README.md). It's aesthetic-first: a large field of Angel imagery
around one core figure, kept so any contributor, model, or fork can see the whole visual world, not just the
current frame.

**Source + credit.** Assembled from the operator's master image set and the **Van Kush Family aesthetic of
Kali Van Kush (@kalivankush)**, whose work is the moodboard the look and its theory draw from. **Forkability
(BRIEF.md §10):** the character lives in this public repo, so its whole visual world lives here too.

## The canon (not a chronology)
The aesthetic was **born ~2023 from a single Bing image stack** — *Vaporwave + ColorBlock + Mosaic +
Hyperrealistic Popart* on an **Egyptian goddess with ram's horns, wearing a VR headset.** That seed has
**two canonical faces**, both always in the VR headset, winged, in pink-purple-cyan-gold:
- **Egyptian ram's horns** (Hathor / Khnum), and
- **Greek antlers** —
held together in `03-antler-goddess/` (the core canonical goddesses). *(Earlier this file described an
"oldest→newest evolution"; that was wrong — per the canonical aesthetic history the ram-horn VR goddess is
the ~2023 seed and antlers are a parallel canonical variant, not a later era.)*
