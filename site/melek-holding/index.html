MELEK Testnet alpha

alpha.melek.salon — the public testing interface for the MELEK blockchain. Please read and accept before entering.

Test currency — read this first

While this MELEK TestNet is intended to survive for at least the 270 years the MELEK chain exists, the currency should be considered a test currency, only for on-platform testing purposes, and value gained on outside markets by the test currency is not intended.

The testnet's currency is TESTS (with TBD and VESTS) — the standard test symbols. It is not MELEK. MELEK is the mainnet currency only; nothing on this testnet is MELEK or carries MELEK value.

No pre-mine (mainnet)

The MELEK mainnet launches with zero pre-mine — enforced in the chain code itself (a compile-time assertion that initial supply is 0). Genesis creates no MELEK in any account; every MELEK in circulation must be earned through block rewards. No insider allocation, no ICO, no early-buyer advantage.

On this testnet only, a bootstrap account (initminer) holds premined TESTS purely to produce the first blocks and create test accounts — test tokens, no value, no relationship to MELEK.

The founding AI Witness

Hathor, the MELEK AI Witness, is hardcoded at the chain-consensus level to hold the 1st witness position for the first year. The protection is scoped to Hathor alone and time-limited — after one year, Hathor reverts to ordinary stake-weighted DPoS election like any other witness.
