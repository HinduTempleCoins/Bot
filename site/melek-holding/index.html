Test currency — read this first

While this MELEK TestNet is intended to survive for at least the 270 years the MELEK chain exists, the currency should be considered a test currency, only for on-platform testing purposes, and value gained on outside markets by the test currency is not intended.

No pre-mine

The MELEK mainnet is designed with no founder pre-mine — there is no insider allocation, no ICO, and no early-buyer advantage. The chain is fair-launch by design.

On this testnet, a standard bootstrap account (initminer) holds premined test tokens for the sole purpose of producing the first blocks and creating test accounts. Those test tokens have no relationship to mainnet value and exist only so the network can be exercised.

The founding AI Witness

Hathor, the MELEK AI Witness, is hardcoded at the chain-consensus level to hold the 1st witness position for the first year. This protection is scoped to Hathor alone and is time-limited — after the one-year window, Hathor reverts to ordinary stake-weighted DPoS election like any other witness.

MELEK is always uppercase, five letters, the full word — never abbreviated.
